Get-AADAdminRoleMembers

List members of all Entra administrator roles, inspect one role, or report the roles assigned to a user.

View on GitHub
entrasecuritygovernance

This resource is archived and kept for reference. It is no longer actively maintained; check the README for a current alternative.

What it is

A PowerShell script for reporting Azure AD administrator-role membership across all roles, one named role, or one user.

Why use it

  • Audit privileged role membership across the directory.
  • Answer which administrator roles a particular user belongs to.
  • Inspect the members of a specific administrator role.

How to use it

Install the Azure AD PowerShell module, then run one mode, for example:

.\Get-AADAdminRoleMembers.ps1 -Admin admin@contoso.onmicrosoft.com -All

Prerequisites

  • Azure AD PowerShell module
  • Directory account permitted to read administrator roles
