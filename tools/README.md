# Tools

| Folder | What it is |
|---|---|
| [`SimpleGraph/`](SimpleGraph/) | A lightweight PowerShell module for calling any Microsoft Graph endpoint with simple GET, POST, PATCH, and DELETE cmdlets. |
| [`catalog-build/`](catalog-build/) | The Node tooling that builds the [FastTrack catalog](https://microsoft.github.io/FastTrack/) from resource README front matter, plus the traffic and statistics collectors. This is repo infrastructure, not a resource. |

Larger compiled tools and applications generally belong in their own repository. Open an issue before adding one here. See [CONTRIBUTING.md](../CONTRIBUTING.md).
