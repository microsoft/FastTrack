# Samples

Code samples and snippets for Microsoft Teams and Viva Engage. Each folder has its own README.

| Folder | What it is |
|---|---|
| [`teams-audioconferencing-snippets/`](teams-audioconferencing-snippets/) | PowerShell snippets to update Teams Audio Conferencing bridge numbers and policies in bulk. |
| [`teams-phonesystem-snippets/`](teams-phonesystem-snippets/) | PowerShell snippet to assign Teams Phone numbers in bulk from a CSV. |
| [`teams-rooms-snippets/`](teams-rooms-snippets/) | PowerShell snippets to create and configure Microsoft Teams Rooms resource accounts. |
| [`teams-upgrade-snippets/`](teams-upgrade-snippets/) | Archived Skype for Business to Teams upgrade snippets, kept for reference. |
| [`Viva-Engage-Community-Creation-App/`](Viva-Engage-Community-Creation-App/) | A sample Power App and flow that create Viva Engage communities (preview). |

Browse and filter them in the [catalog](https://microsoft.github.io/FastTrack/). These are samples: test in a non-production environment first.
