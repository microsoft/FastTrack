# Scripts

PowerShell scripts for Microsoft 365 administration, built and shared by FastTrack engineers and the community. Each folder has its own README that explains what the script does, what it needs, and how to run it.

The easiest way to browse and filter them is the [catalog](https://microsoft.github.io/FastTrack/?type=script). It also groups related scripts into paths such as [Viva Engage administration](https://microsoft.github.io/FastTrack/?collection=viva-engage) and [Prepare your tenant](https://microsoft.github.io/FastTrack/?collection=prepare-tenant).

## Before you run anything

- Read the script and its README first, and test in a non-production tenant.
- Scripts that change or delete data are marked clearly in their README. Several default to a dry run; check the README to see how.
- Folders marked **Archived** in their README depend on retired modules or services and are kept for reference. Their READMEs name the current alternative.

## Folders

- Active scripts live directly in this folder, one folder per script.
- [`archive/`](archive/) holds retired scripts kept for reference.

## Contributing

Put new scripts in a slug-cased folder here and start from [TEMPLATE-README.md](../TEMPLATE-README.md). See [CONTRIBUTING.md](../CONTRIBUTING.md).
