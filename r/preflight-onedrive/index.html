Preflight-OneDrive

Scan a local or network folder for potential OneDrive for Business sync issues and optionally generate an HTML report.

View on GitHub
onedrivemigration

What it is

A PowerShell preflight scanner that checks a local folder or UNC path for potential OneDrive for Business synchronization issues.

Why use it

  • Find problematic paths before deploying the OneDrive sync client.
  • Review results in the console or an optional HTML report.

How to use it

Install the external dependencies, then run:

.\Preflight-OneDrive.ps1 -Path "\\dc.contoso.com\smb" -GenerateHTMLReport

Prerequisites

  • EnhancedHTML2 module
  • Test-OneDrivePath function
  • Read access to the folder being scanned
