1. Agent and billing scope

Which harness and costs does this cover?

Standard harness: feature meters, token-metered AI tools, agent flows and separately billable integrations. Copilot Chat harness: Agent Builder and SharePoint scenarios with explicit graph-grounded messages. Agent Builder's non-graph generative responses are exempt.

GitHub Copilot harness: models, runtime, context and tools consume credits. LLM-powered creation, preview, testing and evaluations are billable; manual non-LLM configuration is not. Use measured all-in credits per task here; the standard feature table must not be applied to this harness. This is Copilot Studio technology, not a GitHub Copilot subscription.

Microsoft Foundry: model inference, tools and optional infrastructure allowances. Hosted agents also incur container compute. Work IQ API calls can add Copilot Credits alongside Azure charges.

3. Licence eligibility, not a blanket discount

Enter the share of usage, not headcount. Fair-use limits apply. Coverage is limited to eligible Standard / Copilot Chat usage. Work IQ APIs, computer use, external services and non-agent-triggered agent flows remain separately billable. A Microsoft Copilot licence does not cover GitHub Copilot harness runtime.

4. Billable operations in one conversation or run

Count operations, not user turns: one turn may use several meters. Include only actual generative responses. No answer or action is automatically added for a knowledge source or generic tool call.

Agent Builder: generative responses without tenant graph grounding are exempt; graph-grounded responses use the normal generative + graph meters. SharePoint agents are not automatically assigned the Agent Builder exemption.

Prompt tools in topics or actions

Reasoning-model usage

Token inputs include metaprompts, instructions and retrieved data. Output includes reasoning and final output. Prompt and reasoning estimates use started 1,000-token units per invocation, following the AI-tool example; actual meter aggregation can differ. Fractional credits are retained.

Agent flows (not Power Automate cloud flows)

A topic invocation adds one classic answer; a generative invocation adds one agent action. Do not count that same invocation again above. Add a generative answer only if one is actually returned. Independently triggered flows do not receive the user's licence exemption.

AI tools inside agent flows

These counts are per conversation/run across all flows, not per flow. AI prompts and models inside flows are billable even in designer tests. Flow-action testing exemptions do not make these AI tools free.

Document/image processing and excluded features

The content-processing meter applies to the relevant AI capability, not automatically to every PDF used as knowledge. Documents passed to a prompt may instead consume tokens. Computer-use and other excluded-feature credit allowances below are never licence-zero-rated; add external Azure costs separately.

4. GitHub Copilot harness: measured task budget

There is no universal per-answer tariff here. Supply observed or explicitly assumed all-in credits per task (including models, runtime, context and tools), plus a separate creation/evaluation budget for the selected period. Do not add already-included Work IQ consumption twice. Blank measurements block the estimate; zero is an explicit assumption, not an inferred free tier.

4. Microsoft Foundry model, tokens and tools

Not live-priced. Legacy model/tool values are retained as a May 2026 historical snapshot. New catalogue entries have no invented prices. Enter a current Azure rate or quote for the exact model, deployment and context tier. Non-global or long-context selections require replacement rates.

Model calls and context assumptions

Each model call includes instructions, schemas, the current user message, retrieval and tool results. Additional calls in a turn include earlier intermediate outputs/tool results. Only the final visible response is carried to later turns; reasoning output is billed but not resent. This is an explicit approximation, not a provider token trace. Use measured averages, including retry calls.

Built-in tools

The file-search call fee applies to Responses API usage; storage is separate. A Code Interpreter session is not a tool call: reuse and concurrent conversations affect session counts (one-hour default lifetime; idle timeout also applies). Tool price edits are user assumptions, not verified rates.

Infrastructure for the selected period

Enter actual billable provisioned/idle hours, not just request time. Storage is billed on GB-days after the entered free allowance. Include Azure AI Search or other retrieval infrastructure in the search allowance, without double counting vector storage. For a test budget these are test-period amounts; for production they are monthly amounts. Zero means not estimated.

5. Separately billed integrations

Work IQ Tools API: 0.1 Copilot Credit per call. Work IQ Chat/Context API: variable consumption; enter measured credits rather than assuming a fixed rate. Both remain billable for licensed Copilot users, including when called from Foundry. This does not change the distinct licensing of older Retrieval/Chat APIs or native Work IQ within Copilot.

6. Purchase commitment and available capacity

Purchase scenarios assume a new, unused plan for this workload only. Credit packs have monthly capacity, annual billing and no monthly rollover. P3 pools expire after one year. Discounted allocation is not the invoice or a promise of savings. Discounts do not stack; reservations apply before P3, and Copilot Credit P3 before Agent P3.

Capacity monitoring is independent of the hypothetical purchase comparison. Enter the full applicable monthly allocation (not the remaining balance), then consumption already charged against it. This is a projection, not a live tenant report. Existing P3 balances and other workloads drawing from shared plans are not simulated.

Capacity enforcement and costs outside this estimate

Standard harness: custom agents can be disabled at 125% of the applicable prepaid pool. New agent-flow runs can be blocked when prepaid capacity is fully consumed (100%); existing runs finish. Supported test runs and eligible licensed-user flow runs are exempt. Configured PAYG can handle overage; a spending alert alone is not a hard cap.

GitHub Copilot harness: credit-dependent authoring and runtime can stop when allocated credits are exhausted. Do not assume a universal 125% grace allowance. Agent Builder, SharePoint and separately billed services have their own policies.

Not automatically estimated: Dataverse storage overage, standalone Power Automate licensing, telephony/voice, provisioned model throughput, networking, image/audio/video generation, support, implementation labour, and third-party subscriptions. Use explicit allowances or a separate estimate. No Microsoft Copilot user licence acquisition cost is included.
