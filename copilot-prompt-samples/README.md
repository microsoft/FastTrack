# Prompt samples (archived)

FastTrack no longer maintains a prompt library, and this folder is kept for reference only.

The one sample here, [Researcher: Automation Opportunities](Researcher-OrganizationInsights.md), was written for the Microsoft 365 Researcher agent in May 2025. It is hidden from the [FastTrack catalog](https://microsoft.github.io/FastTrack/) by default.

## Looking for prompts?

- [PnP Copilot Prompts](https://pnp.github.io/copilot-prompts/) is a community-maintained, searchable collection of prompts, agents, and skills for Microsoft Copilot that is updated frequently.
- For FastTrack-built agents, guides, and tools, browse the [catalog](https://microsoft.github.io/FastTrack/).

## Contributing

We are not accepting new prompt samples here. If you have a prompt to share, contribute it to PnP Copilot Prompts. If you have a FastTrack-style tool, agent, or guide, see [CONTRIBUTING.md](../CONTRIBUTING.md).
