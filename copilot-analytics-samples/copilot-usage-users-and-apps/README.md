# Copilot Usage Dashboard: Users and Apps (retired)

This sample Power BI template was retired by its author and removed from the repository in July 2026.

Looking for Copilot usage reporting? These FastTrack resources are maintained:

- [Viva Insights Copilot Dashboard](https://microsoft.github.io/FastTrack/r/viva-insights-copilot-dashboard/): a Power BI starting point built on a Viva Insights person query export, with leaderboards, weekly trends, and per-app breakdowns.
- [Purview Audit Copilot Report](https://microsoft.github.io/FastTrack/r/purview-audit-copilot-report/): Copilot adoption by user, app, and department from Purview audit data.
- [Copilot Interaction Report](https://microsoft.github.io/FastTrack/r/copilot-interaction-report/): an HTML usage dashboard generated from Copilot interaction history.
- [Copilot Analytics Reports Navigator](https://microsoft.github.io/FastTrack/r/copilot-analytics-reports-navigator/): compare Microsoft and community Copilot analytics reports by purpose and metrics.

Browse everything in the [Analytics](https://microsoft.github.io/FastTrack/?type=analytics) section of the catalog.
