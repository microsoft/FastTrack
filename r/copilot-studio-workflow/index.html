Copilot Studio Workflow

Use source control, local YAML, preflight checks, and repeatable packaging to build Copilot Studio agents like software.

View on GitHub
devopscopilot-studiopackaging

What it is

An Agent Skills-compatible workflow with scripts and guidance for pulling, editing, validating, pushing, publishing, and packaging Copilot Studio YAML projects.

Why use it

  • Keep Copilot Studio definitions in Git and review intentional source changes.
  • Catch dirty workflow files, missing variables, and solution-membership gaps before deployment.
  • Reuse known workarounds for common pull, push, packaging, and environment-portability problems.

How to use it

Install with:

copilot plugin install microsoft/FastTrack:copilot-agent-samples/github-copilot-skills/copilot-studio-workflow

Then ask Copilot to pull, validate, push, or package a Copilot Studio project. Run the included preflight and status scripts when prompted.

Prerequisites

  • Git
  • VS Code with the Copilot Studio extension
  • PowerShell
  • Copilot Studio-enabled Power Platform environment
  • Power Platform CLI recommended
