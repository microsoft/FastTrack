Disable-InsightsHeadSpace

Disable the retired Headspace feature in Viva Insights for every user with a Personal Insights service plan.

View on GitHub
viva-insightsheadspaceadministrationexchange-online

This resource is archived and kept for reference. It is no longer actively maintained; check the README for a current alternative.

What it is

A PowerShell script that uses Microsoft Graph to find users assigned the Exchange Analytics or MyAnalytics (Personal Insights) service plans and runs Set-VivaInsightsSettings -Feature headspace -Enabled $false for each of them through Exchange Online. Microsoft has removed Headspace from Viva Insights, so it is kept for reference only.

Why use it

  • Reference for how Viva Insights features were disabled per user with Set-VivaInsightsSettings.
  • Example of filtering users by service plan ID with the Microsoft Graph PowerShell module.

How to use it

  1. Install the Microsoft Graph PowerShell (Microsoft.Graph.Users) and Exchange Online (ExchangeOnlineManagement) modules.
  2. Run the script and sign in to Microsoft Graph (User.Read.All) and Exchange Online when prompted:
.\Disable-InsightsHeadSpace.ps1

Prerequisites

  • Microsoft.Graph.Users and ExchangeOnlineManagement PowerShell modules
  • Account that can consent to the User.Read.All Microsoft Graph scope and run Set-VivaInsightsSettings in Exchange Online
