Viva Insights Copilot Dashboard

Visualize a Viva Insights Advanced Insights person-query export in Power BI, including dynamic personas and usage profiles.

View on GitHub
power-biviva-insightsadoption

What it is

A pair of Power BI templates that visualize Viva Insights Advanced Insights person-query exports, including a dynamic-personas view with user-profile usage.

Why use it

  • Explore Copilot adoption alongside collaboration and organizational attributes.
  • Start from a reusable Power BI model instead of designing a dashboard from scratch.

How to use it

Download the PBIX file that matches the desired dashboard, review the included Word instructions, export the required Viva Insights Advanced Insights person query, and update the report data source before refreshing.

Prerequisites

  • Microsoft Viva Advanced Insights
  • Power BI Desktop
  • Viva Insights person-query export
